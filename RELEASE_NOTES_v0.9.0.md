# StroyBase v0.9.0 — Первая публичная бета

Добро пожаловать в открытую версию StroyBase!

Это первая публичная версия платформы для цифровизации ПТО строительных организаций.

## Что уже работает

- Полная иерархия: Проект → Корпус → Этаж
- Галерея фото/видео/документов с фильтрами и привязкой к маркерам на плане
- Материалы: план/факт, остатки на складе, сертификаты
- Движение материалов (приход/расход/перемещение)
- План и график работ + ежедневный учёт выполнения
- Gantt-план (Mermaid)
- Учёт людей по дням (день/ночь)
- Импорт/экспорт работ из Excel
- Миграции БД через Flask-Migrate (`flask db upgrade`)

## Что хотим развивать дальше (приглашаем к участию)

- Мобильная адаптивность / PWA
- Задачи и уведомления
- Экспорт отчётов (PDF, Excel)
- Справочник поставщиков и сметы
- Интеграция с ИИ (анализ фото, прогнозы)

## Установка — 5 минут

```bash
git clone https://github.com/<your-org>/stroybase.git
cd stroybase
python -m venv venv
venv\Scripts\activate  # или source venv/bin/activate
pip install -r requirements.txt
flask db upgrade
flask run
```
