# Концепция «Движение материалов» и разделение проектных/фактических материалов

## Одна таблица материалов на этаже

На странице этажа (вкладка «Тех. информация») — **одна таблица** «Материалы на этаже»:

- **Строки** — записи о движении (MaterialMovement) с привязкой к этому этажу (`floor_id`). В перспективе привязка к этажу может учитывать маркер на плане (при выборе этажа и маркера запись движения связывается с этажом).
- **Столбцы**: Наименование, Бренд, **Проектный объём**, Кол-во, Ед., Тип, Дата, Действия.
- **Проектный объём** — один столбец: берётся из позиций плана по ТХ (таблица `floor_materials`, FloorMaterial) при совпадении наименования материала на этом этаже. Если по названию есть несколько позиций плана — суммируются их плановые количества.
- Кнопки над таблицей: **«План (ТХ)»** — добавить/редактировать позиции по проектной документации (FloorMaterial); **«Движение»** — добавить приход/расход в разделе «Движение материалов» с подставленным этажом.

---

## Назначение раздела «Движение материалов»

**Фактические материалы** — раздел **Движение материалов** (таблица `material_movements`). Проект, корпус и этаж — привязка записи к объекту. На странице этажа в блоке «Фактические материалы (движение)» отображаются записи с привязкой к этому этажу. Добавление — через модальное окно в разделе «Движение материалов» или по кнопке «Добавить запись о движении» на этаже; документы (накладная, УПД, сертификаты) прикрепляются при редактировании записи.

---

## Сущность: запись о движении материала (MaterialMovement)

Одна запись = один материал, привязанный к объекту (проект обязательно, корпус/этаж — по необходимости).

### Привязка к объекту
- **Проект (объект)** — обязательно. Объект, на который заказан/поставлен материал.
- **Корпус** — опционально. Уточнение по корпусу.
- **Этаж** — опционально. Уточнение по этажу.

### Данные о материале
- **Наименование** — название материала.
- **Бренд / производитель** — по желанию.
- **Количество** — число.
- **Единица измерения** — м, м², м³, шт, л, кг, т, пог.м, упак., комплект и т.д.
- **Объём, м³** — при необходимости (объёмы).
- **Длина, м** — при необходимости (линейные размеры).
- **Вес, кг** — при необходимости (масса).
- **Тип движения** — Приход / Расход / Перемещение.
- **Дата движения** — дата операции.
- **Примечание** — произвольный комментарий.

Документы (накладная, УПД, сертификаты) к записи **не обязательны при создании**. Их прикрепляют при редактировании записи.

---

## Документы к записи о движении

К одной записи о движении можно привязать несколько документов. Тип документа задаётся при привязке:

| Тип документа   | Описание |
|-----------------|----------|
| **Накладная**   | Товарная накладная (ТОРГ-12 и др.) |
| **УПД**         | Универсальный передаточный документ |
| **Сертификат**  | Сертификат соответствия, паспорт качества |
| **Другое**      | Иные документы (акт, договор и т.п.) |

- Документы хранятся в общей таблице документов (project_id = объект движения, при необходимости building_id/floor_id).
- Связь «запись о движении ↔ документ» хранится в таблице `movement_documents` с полем типа документа (invoice, upd, certificate, other).
- При редактировании записи отображается блок «Документы»: список привязанных (название, тип, ссылка на файл) и возможность добавить новый файл с выбором типа.

## Сценарии использования

### 1. Добавление записи (модальное окно)
- Пользователь на странице «Движение материалов» (или в блоке материалов на объекте) нажимает «Добавить движение».
- Открывается модальное окно:
  - Выбор объекта: проект (обязательно), корпус, этаж.
  - Наименование, бренд, количество, ед. изм., при необходимости объём, длина, вес.
  - Тип движения, дата, примечание.
- Кнопка «Сохранить» — запись создаётся, модальное окно закрывается. Документы не требуются.
- При необходимости пользователь сразу переходит в редактирование этой записи и прикрепляет накладную/УПД/сертификаты.

### 2. Редактирование записи
- Открывается страница редактирования записи о движении.
- Редактируются все поля (объект, материал, количество, объём, длина, вес, тип, дата, примечание).
- Блок **«Документы»**:
  - Таблица привязанных документов: тип (Накладная / УПД / Сертификат / Другое), название, ссылка «Открыть», кнопка «Отвязать».
  - Кнопка «Прикрепить документ»: выбор типа + загрузка файла. Файл сохраняется как документ проекта и привязывается к записи с выбранным типом.

### 3. Просмотр материалов на объекте
- На дашборде проекта (или отдельной вкладке «Материалы» по объекту) выводится таблица записей о движении по этому проекту (фильтр project_id).
- Колонки: объект (корпус/этаж при наличии), наименование, бренд, количество, ед. изм., объём/длина/вес (если заданы), тип движения, дата, количество привязанных документов, действия (редактировать).
- По клику «Редактировать» — переход на страницу редактирования записи (с возможностью привязывать документы).

---

## Таблицы БД (кратко)

- **floor_materials** — проектные материалы по этажу (план/факт, бренд, ГОСТ, единица, цена, сертификат). Одна запись = одна позиция по ТХ/проектной документации.
- **material_movements** — фактические записи о движении (приход/расход/перемещение); поля: `brand`, `volume_m3`, `length_m`, `weight_kg` (все nullable).
- **movement_documents** — связующая таблица: `movement_id`, `document_id`, `doc_type` (invoice / upd / certificate / other), при необходимости `description`, `order`.

Документы хранятся в **documents**: при привязке к движению у документа заполняется `project_id` объекта движения; файл загружается в хранилище проекта.

---

## Итог

- **Добавление**: модальное окно → объект + название, бренд, количество, объёмы/длины/веса, тип, дата, примечание. Без документов.
- **Редактирование**: те же поля + блок «Документы» для привязки накладной, УПД, сертификатов (и просмотра/отвязки).
- **На объекте**: список материалов (движений) по проекту с возможностью открыть запись и отредактировать/привязать документы.
