# Интерфейс StroyBase

## Общая структура

- **Одна боковая панель (слева):** тёмная глобальная навигация с иерархическим деревом «Объекты → Проекты → Корпуса → Этажи». Содержит пункты «Все объекты», раскрываемые проекты (Дашборд, список корпусов), внутри корпуса — «Обзор корпуса» и этажи. Блоки «Инструменты» и «Администрирование» внизу.
- **Основная область:** контент страницы на всю оставшуюся ширину. На мобильных боковая панель скрывается (оверлей при открытии).

## Страницы корпуса и этажа

- Та же схема: **одна колонка**, без второй боковой панели.
- **Верхняя панель:** «Назад к объекту» / «Назад к корпусу», «Загрузить фото/документы», **«Редактировать»** и **«Удалить»** (рациональное место — рядом с навигацией).
- **Корпус:** под вкладками — секция **«Этажи корпуса»** с сеткой карточек (row-cols-1 / md-3 / lg-4), кнопка «Добавить этаж», в карточке этажа — «Открыть», «Редактировать», «Удалить».
- **Этаж:** под заголовком — краткие детали (тип, площадь, заметка); кнопки «Редактировать» и «Удалить» в верхней панели.

## Страница проекта (дашборд объекта)

- **Вторая (контекстная) боковая панель удалена.** Раньше справа от вкладок отображался блок с названием проекта, кнопкой «Загрузить фото/документы» и списком корпусов с кнопками «Открыть», «Ред.», «Уд.».
- **Одна колонка контента:**
  - Вверху: кнопки «Назад ко всем объектам», «Загрузить фото/документы», справа — общая площадь и адрес/договор.
  - Заголовок «Проект «…»» и вкладки: Фото и видео, Документы, Тех. информация, План и график работ, Исполнители работ, Движение материалов.
  - Под вкладками — секция **«Корпуса проекта»**: крупная кнопка «Добавить корпус», затем адаптивная сетка карточек (Bootstrap `row-cols-1 row-cols-md-3 row-cols-lg-4`). На мобильных карточки в один столбец, на планшетах — 3, на десктопе — 4.
- **Карточка корпуса:** название, тип (класс/вид работ), при наличии — бейдж с числом этажей; кнопки «Открыть», «Редактировать», «Удалить» с `aria-label` для доступности.
- **Доступность:** у кнопок действий указаны `aria-label`, в CSS заданы видимые `:focus-visible` обводки.

## Адаптивность

- Основная область имеет отступы: на мобильных меньше (`p-3`), на планшетах и десктопе больше (`p-md-4`, отдельные медиазапросы в `style.css` для `.sb-project-dashboard`).
- Сетка корпусов штатно перестраивается: вертикальный столбец на узких экранах, несколько колонок на широких.
