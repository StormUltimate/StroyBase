# Действующие функции StroyBase (по факту)

Краткое описание реализованного и работающего функционала по текущему коду.

---

## 1. Авторизация (`/auth`)

| Функция | URL | Описание |
|--------|-----|----------|
| **Вход** | `GET/POST /auth/login` | Страница входа по логину и паролю; после входа редирект на главную. |
| **Выход** | `GET /auth/logout` | Выход из системы, очистка сессии, редирект на страницу входа. |

Доступ к объектам, загрузке файлов и материалам возможен только после входа (глобальный `before_request`).

---

## 2. Главная страница и объекты (`/`)

| Функция | URL | Описание |
|--------|-----|----------|
| **Список объектов** | `GET /` | Таблица всех проектов (название, договор, адрес, вид стройки, даты). Кнопки: Открыть, Редактировать, Удалить. |
| **Создать объект** | `GET/POST /create_project` | Форма создания проекта (название, договор, адрес, вид строительства, даты). Создаётся папка в `media/projects/<id>`. |
| **Редактировать объект** | `GET/POST /project/<id>/edit` | Редактирование полей проекта. |
| **Удалить объект** | `POST /project/<id>/delete` | Удаление проекта, папки медиа и каскадно зданий/этажей/документов. Flash: «Строительная площадка успешно удалена», редирект на `/`. |

---

## 3. Проект — дашборд и документы (`/project/<id>/...`)

| Функция | URL | Описание |
|--------|-----|----------|
| **Дашборд проекта** | `GET /project/<id>/dashboard` | Сводка по проекту: список корпусов, загрузка документов, вкладки «Фото/видео» и «Документы» с фильтрами (корпус, вид работ, даты, тип медиа). |
| **Создать корпус (простая форма)** | `GET/POST /project/<id>/create_building` | Минимальная форма: только название корпуса. |
| **Загрузить документы в проект** | `POST /project/<id>/upload_documents` | Множественная загрузка файлов с привязкой к корпусу/этажу, видам работ, названию и описанию. Генерация превью для изображений. |
| **Удалить документ (на уровне проекта)** | `POST /project/delete_document/<doc_id>` | Удаление записи документа из БД (файл на диске не удаляется). Редирект на дашборд проекта. |
| **Финансы** | `GET /project/<id>/finance` | Пустая страница-заглушка. |
| **Фото проекта** | `GET /project/<id>/photos` | Роут есть, обработчик не реализован (`pass`). |

---

## 4. Корпуса (`/buildings/...`)

| Функция | URL | Описание |
|--------|-----|----------|
| **Создать корпус (полная форма)** | `GET/POST /buildings/create/<project_id>` | Форма: название, класс строения, вид работ, примечание, цвет метки. |
| **Просмотр корпуса** | `GET /buildings/<id>` | Список этажей, галерея медиа/документов по корпусу, кнопки: добавить этаж, загрузить документы, редактировать/удалить этажи. |
| **Редактировать корпус** | `GET/POST /buildings/edit/<id>` | Изменение названия, класса, вида работ, примечания. |
| **Удалить корпус** | `POST /buildings/delete/<id>` | Удаление корпуса и каскадно этажей и связей с документами. |
| **Загрузить документы в корпус** | `POST /buildings/<id>/upload_documents` | Загрузка файлов с привязкой к этажу (опционально), видам работ, превью для картинок. |
| **Удалить документ (в корпусе)** | `POST /buildings/delete_document/<doc_id>` | Удаление документа из БД. |
| **Просмотр/скачивание файла** | `GET /buildings/document/<doc_id>/view` | Безопасная выдача файла по `doc_id` с проверкой принадлежности корпусу. |

## 5. Этажи (`/floor/...`)

| Функция | URL | Описание |
|--------|-----|----------|
| **Создать этаж** | `GET/POST /floor/create/<building_id>` | Название этажа и тип (по умолчанию «Обычный этаж»). |
| **Просмотр этажа** | `GET /floor/<floor_id>` | Вкладки: медиа, документы, планы этажей, тех. информация (материалы). Галерея, кнопки загрузки и редактирования. |
| **Редактировать этаж** | `GET/POST /floor/edit/<floor_id>` | Название, тип этажа, площадь, общая площадь, примечание. |
| **Удалить этаж** | `POST /floor/delete/<floor_id>` | Удаление этажа и каскадно связанных данных. |
| **Загрузить документы на этаж** | `POST /floor/<floor_id>/upload_documents` | Множественная загрузка с видами работ, названием и описанием. |
| **Добавить материал на этаж** | `GET/POST /floor/<floor_id>/create_material` | Форма добавления материала этажа (название, марка, ГОСТ, план/факт, цена, единица, сертификат, заметка). |
| **Редактировать материал этажа** | `GET/POST /floor/<floor_id>/edit_material/<material_id>` | Редактирование полей материала. |
| **Удалить материал этажа** | `POST /floor/<floor_id>/delete_material/<material_id>` | Удаление материала этажа. |
| **План этажа** | `GET /floor/<floor_id>/plan/<plan_id>` | Страница плана: изображение, переключение планов, загрузка нового плана, печать, галерея фото с метками, фильтры по датам и видам работ. |
| **Загрузить план этажа** | `POST /floor/<floor_id>/upload_plan` | Загрузка плана (изображение или PDF с выбором страницы), создание записи `Plan`. |
| **Редактировать документ** | `GET/POST /edit_document/<doc_id>` | Название, описание, привязка к метке на плане, виды работ. |
| **Удалить документ (на этаже)** | `POST /delete_document/<doc_id>` | Удаление документа из БД. |
| **Просмотр/скачивание документа** | `GET /document/<doc_id>/view` | Выдача файла с проверкой принадлежности этажу. |

Роут печати плана (`print_plan`) в коде закомментирован; при необходимости используется кнопка «Печать» в браузере на странице плана.

## 6. Движение материалов (`/movement/...`)

| Функция | URL | Описание |
|--------|-----|----------|
| **Список материалов** | `GET /movement/` | Таблица материалов с фильтрами: проект, корпус, этаж, статус, категория. Пагинация (50 на страницу). |
| **Редактировать материал** | `GET/POST /movement/edit/<material_id>` | Редактирование материала (название, марка, ГОСТ, единица, план/факт, цена, статус, категория, сертификат и т.д.). |
| **Загрузить документ к материалу** | `POST /movement/<material_id>/upload-document` | Привязка файла (сертификат, накладная и т.п.) к материалу. |
| **Создать заказ на закупку** | `GET/POST /movement/<material_id>/create-order` | Форма заказа: поставщик, количество, цена, дата доставки, статус. Обновление планового количества и при необходимости статуса материала. |
| **Создать материал (общий)** | `GET/POST /movement/create-material` | Создание материала без привязки к этажу (для общего справочника/движения). |

## 7. Администрирование пользователей

| Функция | URL | Описание |
|--------|-----|----------|
| **Список пользователей** | `GET /users` | Таблица пользователей (доступ временно по факту без жёсткой проверки роли admin). |
| **Добавить пользователя** | `GET/POST /users/add` | Логин, ФИО, роль, активность, пароль. |
| **Редактировать пользователя** | `GET/POST /users/edit/<user_id>` | Изменение полей и пароля. |
| **Удалить пользователя** | `POST /users/delete/<user_id>` | Удаление пользователя (нельзя удалить себя). |

Проверка роли «admin» в коде отключена (все авторизованные могут заходить в раздел).

---

## 8. Общее по приложению

- **Иерархия:** Проект → Корпус → Этаж. Документы и планы привязаны к проекту/корпусу/этажу; материалы — к этажу и дополнительно к заказам и категориям.
- **Медиа:** Файлы хранятся в `app/static/media/` (по проектам/корпусам/этажам и отдельно планы в `media/plans/<floor_id>`). Для изображений при загрузке создаются превью.
- **Справочники:** Типы документов (виды работ) — модель `DocType`; категории материалов — `MaterialCategory`. Заполнение типов документов — скрипт `seed_doctypes.py`.
- **Безопасность:** CSRF на формах, обязательная авторизация для всех страниц кроме входа и статики, проверка принадлежности документа корпусу/этажу при просмотре файла.
- **Интерфейс:** Общий layout с тёмной боковой панелью (навигация, выход), Bootstrap 5 по CDN, основной стиль — `static/css/style.css`.

---

## 9. Что не реализовано или заглушено

- **Печать плана этажа** — отдельный роут отключён; используется встроенная печать браузера со страницы плана.
- **Фото проекта** — `/project/<id>/photos` не отдаёт шаблон.
- **Финансы проекта** — страница есть, контента нет.
- **Жёсткая проверка роли admin** — отключена, раздел пользователей доступен всем вошедшим.

Файл актуален для текущей версии кода.
